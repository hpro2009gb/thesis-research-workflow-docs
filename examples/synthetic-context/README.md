# Fictional research context for a workflow demonstration

This folder is a **wholly synthetic, fictional research context**. It does not describe a real student, laboratory, institution, thesis, model or publication. All numbers are invented for demonstrating artifact boundaries; they are **not scientific evidence**.

Files follow the six-file Context Pack pattern: intake, table of contents, evidence/contribution mapping, toy method/data, writing policy and gap register. No real DOI, publication, experiment, credential or personal identifier is included.

A future separate-account canary may use this fixture to test task routing and Human approval boundaries, but **such a canary has not yet been run** for the public candidate.
